# ScriptsPool — 代码打字动效生成器

把代码片段变成逐字敲出的打字动画，直接产出短视频素材。全程在浏览器完成，无需注册。

🔗 **在线使用**：[scriptspool.pixzens.com](https://scriptspool.pixzens.com/zh)

## 怎么用

1. 粘贴代码片段
2. 选择动效样式
3. 导出 MP4 或 GIF

## 特点

- **零安装**：纯浏览器运行，不用装客户端
- **免注册**：打开即用
- **两种导出**：MP4 适合视频剪辑，GIF 适合文档和聊天嵌入

## 适合谁

| 场景 | 说明 |
| --- | --- |
| 抖音 / 小红书 | 竖屏代码演示片段 |
| 教程录制 | 讲解时的代码逐行呈现 |
| 技术文档 | GIF 嵌入 README 或 Wiki |
