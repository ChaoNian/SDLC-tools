# Miro — 在线协作白板

以 AI 为基础的在线协作平台，专为创新领域设计，让不同规模的分布式团队在同一块画板上共同构思、设计并构建未来的愿景。

🔗 **在线体验**：[打开示例画板](https://miro.com/app/board/uXjVHyDl1BE=/)

## 核心能力

- **协作白板**：多人实时编辑，支持便利贴、流程图、思维导图
- **AI 辅助**：自动整理便利贴、生成图表与摘要
- **原型设计**：低保真线框图到可点击原型，可直接嵌入需求文档
- **模板库**：用户旅程图、故事地图、Sprint 看板等开箱即用

## 适用场景

| 场景 | 用法 |
| --- | --- |
| 需求梳理 | 用户旅程图 + 便利贴收敛 |
| 方案评审 | 架构图/流程图集中标注讨论 |
| 原型验证 | 低保真原型走查交互路径 |
